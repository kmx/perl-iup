=head1 NAME

IUP::GL::SizeBox - [GUI element] GL-based sizebox

=head1 DESCRIPTION

A resizable container drawn by IUP on a GL canvas, allowing the user to
drag-resize its child. It is a void container that lets its child be
expanded and contracted in one or two directions. It inherits from
L<IUP::GL::SubCanvas|IUP::GL::SubCanvas> and exists only inside an
L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>. (since iup-3.11)

=head1 USAGE

=head2 CREATION - new() method

 my $sb = IUP::GL::SizeBox->new( child=>$something );

B<child>: Identifier of an interface element which will receive the box.
It can be C<undef>.

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

=head2 ATTRIBUTES

=item B<FORECOLOR>

Changes the color of the bar handler. Default: "192 192 192".

=item B<RESIZERS>

Indicates the direction of the resize. Possible values are "VERTICAL",

at the right/bottom of its child.

I<(non inheritable)>

=head1 NOTES

The control inside the L<IUP::GL::SizeBox|IUP::GL::SizeBox> will have its B<User>
size changed. See the L<Layout Guide|../layout_guide.html> for more details
on sizes.

L<IUP::GL::SizeBox|IUP::GL::SizeBox> can make the layout to be resized larger
than the L<IUP::GL::CanvasBox|IUP::GL::CanvasBox> size, so some controls will be
positioned outside the box area at right or bottom. In fact this is part of
the dynamic layout default reposition of controls inside the box. See the
L<IUP::Refresh|IUP::Refresh> function. The IUP layout does not have a maximum
limit, only a minimum, except if you use the MAXSIZE common attribute.

The box can be created with no elements and be dynamically filled using
L<IUP::Append|IUP::Append> or L<IUP::Insert|IUP::Insert>.
