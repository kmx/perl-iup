=head1 NAME

IUP::GL::ScrollBox - [GUI element] GL-based scroll box

=head1 DESCRIPTION

A scrollable container drawn by IUP on a GL canvas. It creates an
embedded OpenGL container that allows its child to be scrolled, showing
or hiding scrollbars automatically when the child does not fit the
visible area. It inherits from L<IUP::GL::SubCanvas|IUP::GL::SubCanvas>
and exists only inside an L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>.
(since iup-3.11)

=head1 USAGE

=head2 CREATION - new() method

 my $sb = IUP::GL::ScrollBox->new( child=>$something );

B<child:> (named parameter) reference to an interface element which will
receive the box. It can be C<undef>.

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

NOTE: You can pass to C<new()> other C<ATTRIBUTE=E<gt>'value'> or C<CALLBACKNAME=E<gt>\&func> pairs relevant
to this element - see L<IUP::Manual::02_Elements|IUP::Manual::02_Elements/"new()">.

=head2 ATTRIBUTES

For more info about concept of attributes (setting/getting values etc.)
see L<IUP::Manual::03_Attributes|IUP::Manual::03_Attributes>. Attributes specific to this element:

The L<IUP::GL::ScrollBox|IUP::GL::ScrollBox> element handles all
attributes defined for a L<IUP::GL::SubCanvas|IUP::GL::SubCanvas>
control. It contains automatic scrollbars that are shown or hidden
according to whether the child natural size fits the client size. See
the Scrollbars Attributes for L<IUP::GL::Controls|IUP::GL::Controls> for
more details.

=over

=item L<EXPAND|IUP::Manual::03_Attributes/EXPAND>

I<(non inheritable)>

The default value is "YES".

=item B<POSX>

Position of the thumb in the horizontal scrollbar. Default: "0.0". DX is
the visible horizontal area and XMAX is set to the child natural width.

=item B<POSY>

Position of the thumb in the vertical scrollbar. Default: "0.0". DY is
the visible vertical area and YMAX is set to the child natural height.

=item L<CLIENTSIZE|IUP::Manual::03_Attributes/CLIENTSIZE>, L<CLIENTOFFSET|IUP::Manual::03_Attributes/CLIENTOFFSET> also accepted.

=back

=head1 NOTES

The box allows the application to create a virtual space for the dialog
that is actually larger than the visible area. The current size of the
box defines the visible area. The natural size of the child (and its
children) defines the virtual space size. So the
L<IUP::GL::ScrollBox|IUP::GL::ScrollBox> does not depend on its child
size or expansion, and its natural size is always "0x0".

The user can move the box contents by dragging the background. Also the
mouse wheel scrolls the contents vertically.

The box can be created with no elements and be dynamically filled using
L<Append|IUP::Manual::02_Elements/"Append()"> or L<Insert|IUP::Manual::02_Elements/"Insert()">.
