=head1 NAME

IUP::GL::ProgressBar - [GUI element] GL-based progressbar

=head1 DESCRIPTION

A progress bar drawn by IUP on a GL canvas. It shows a percent value
that can be updated to simulate a progression. It inherits from
L<IUP::GL::SubCanvas|IUP::GL::SubCanvas>, and exists only inside an
L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>. (since iup-3.11)

=head1 USAGE

=head2 CREATION - new() method

 my $pb = IUP::GL::ProgressBar->new( VALUE=>0.3 );

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

=head2 ATTRIBUTES

For more info about concept of attributes (setting/getting values etc.)
see L<IUP::Manual::03_Attributes|IUP::Manual::03_Attributes>. Attributes specific to this element:

The L<IUP::GL::ProgressBar|IUP::GL::ProgressBar> element handles all
attributes defined for the L<IUP::GL::SubCanvas|IUP::GL::SubCanvas> control.

=over

=item B<BACKIMAGE>

I<(non inheritable)>

Image name to be used as background. It will be zoomed to fill the
background (it does not include the border). Use
L<IUP::SetHandle|IUP::SetHandle> or
L<IUP::SetAttributeHandle|IUP::SetAttributeHandle> to associate an image
to a name. See also L<IUP::Image|IUP::Image>. (since iup-3.11.2)

=item B<BACKIMAGEHIGHLIGHT>

I<(non inheritable)>

Background image name of the element in highlight state. If it is not
defined then the BACKIMAGE is used. (since iup-3.11.2)

=item B<BACKIMAGEINACTIVE>

I<(non inheritable)>

Background image name of the element when inactive. If it is not defined
then the BACKIMAGE is used and its colors will be replaced by a modified
version creating the disabled effect. (since iup-3.11.2)

=item B<BACKIMAGEPRESS>

I<(non inheritable)>

Background image name of the element in pressed state. If it is not
defined then the BACKIMAGE is used. (since iup-3.11.2)

=item L<FGCOLOR|IUP::Manual::03_Attributes/FGCOLOR>

Controls the bar color. Can have an alpha component. Default: "200 225 245".

=item B<FITTOBACKIMAGE>

I<(non inheritable)>

Enable the natural size to be computed from the BACKIMAGE. If BACKIMAGE
is not defined it will be ignored. When set to YES it will set
BORDERWIDTH to 0. Can be YES or NO. Default: NO. (since iup-3.11.2)

=item B<MAX>

I<(non inheritable)>

Contains the maximum value. Default is "1".

=item B<MIN>

I<(non inheritable)>

Contains the minimum value. Default is "0".

=item B<ORIENTATION>

Can be "VERTICAL" or "HORIZONTAL". Default: "HORIZONTAL". Horizontal goes
from left to right, and vertical from bottom to top.

=item B<PADDING>

Internal margin. Default value: "0x0".

=item B<CPADDING>

Same as PADDING but using the units of the B<SIZE> attribute. It will
actually set the PADDING attribute. (since iup-3.29)

=item B<SHOWTEXT>

Indicates if the text inside the bar is to be shown or not. Possible
values: "YES" or "NO". Default: "YES".

=item B<TEXT>

I<(non inheritable)>

Contains a text to be shown inside the bar when SHOWTEXT=YES. If it is
C<undef>, the percentage calculated from VALUE will be used.

=item B<TXTCOLOR>

Text color. Can have an alpha component. Default: "0 0 0".

=item B<VALUE>

I<(non inheritable)>

Contains a number between "MIN" and "MAX", controlling the current
position.

=back

=head1 NOTES

The natural size is the height of one character in one direction and the
width of 15 characters in the other, plus PADDING and BORDERWIDTH.
