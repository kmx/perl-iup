=head1 NAME

IUP::GL::Toggle - [GUI element] GL-based two-state (on/off) button

=head1 DESCRIPTION (since iup-3.11)

Creates an embedded OpenGL toggle interface element - a two-state
(on/off) button (checkbox) drawn by IUP on a GL canvas. When selected it
generates an action that activates a function in the associated
application. Its visual representation can contain a text and/or an
image. It inherits from L<IUP::GL::Button|IUP::GL::Button> and exists
only inside an L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>.

=head1 USAGE

=head2 CREATION - new() method

 my $t = IUP::GL::Toggle->new( TITLE=>'Toggle' );

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

=head2 ATTRIBUTES

For more info about concept of attributes (setting/getting values etc.)
see L<IUP::Manual::03_Attributes|IUP::Manual::03_Attributes>. Attributes specific to this element:

=over

=item B<CHECKMARK>

I<(non inheritable)>

Enables the check mark. Default: NO. When
enabled the border and the background are not drawn, and a check mark box
is drawn at left or right, according to RIGHTBUTTON.

=item B<CHECKMARKWIDTH>

I<(non inheritable)>

Size of the check mark. Default: 14.

=item B<RADIO>

I<(read-only)>

Returns if the toggle is inside a radio. Can be
"YES" or "NO". Valid only after the element is mapped, before it returns
C<undef>.

=item B<IGNORERADIO>

I<(non inheritable)>

When set the toggle will not behave
as a radio when inside an L<IUP::Radio|IUP::Radio> hierarchy. (since iup-3.21)

=item B<RIGHTBUTTON>

I<(non inheritable)>

Place the check button at the right
of the text. Can be "YES" or "NO". Default: "NO".

=item B<VALUE>

I<(non inheritable)>

Toggle's state. Values can be "ON", "OFF"
or "TOGGLE". Default: "OFF". The TOGGLE option will invert the current
state.

=back

=head2 CALLBACKS

For more info about concept of callbacks (setting callback handlers etc.)
see L<IUP::Manual::04_Callbacks|IUP::Manual::04_Callbacks>. Callbacks specific to this element:

=over

=item L<ACTION|IUP::Manual::04_Callbacks/ACTION>

Action generated when the toggle's state
(on/off) was changed. The callback also receives the toggle's state.

B<Callback handler prototype:>

 sub action_handler {
   my ($self, $state) = @_;
   #...
 }

=over

B<$self:> reference to the element (IUP::GL::Toggle) that activated the event

B<$state:> 1 if the toggle's state was set to on; 0 if it was set to off.

B<Returns:> IUP_CLOSE will be processed.

=back

=item B<VALUECHANGED_CB>

Called after the value was interactively changed by
the user. Called after the ACTION callback, but under the same context.

B<Callback handler prototype:>

 sub valuechanged_cb_handler {
   my ($self) = @_;
   #...
 }

=over

B<$self:> reference to the element (IUP::GL::Toggle) that activated the event

=back

=back

The following L<common callbacks|IUP::Manual::04_Callbacks/Common Callbacks> are also accepted:

=over

=item * L<MAP_CB|IUP::Manual::04_Callbacks/MAP_CB>,
L<UNMAP_CB|IUP::Manual::04_Callbacks/UNMAP_CB>,
L<GETFOCUS_CB|IUP::Manual::04_Callbacks/GETFOCUS_CB>,

L<HELP_CB|IUP::Manual::04_Callbacks/HELP_CB>

=back

=head1 NOTES

To build a set of mutual exclusive toggles, insert them in a
L<IUP::Radio|IUP::Radio> container. They must be inserted before creation,
and their behavior can not be changed.

A toggle that is a child of an L<IUP::Radio|IUP::Radio> automatically
receives a name when it is mapped into the native system. (since iup-3.16)
