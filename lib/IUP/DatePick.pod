=head1 NAME

IUP::DatePick - [GUI element] date picker

=head1 DESCRIPTION

A dropdown for picking a date. It creates a date editing interface
element, which can display a calendar for selecting a date.
In Windows it is a native element. In GTK and Motif it is a custom
element. In Motif it is not capable of displaying the calendar.

=head1 USAGE

=head2 CREATION - new() method

 my $dp = IUP::DatePick->new();

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

NOTE: You can pass to C<new()> other C<ATTRIBUTE=E<gt>'value'> or C<CALLBACKNAME=E<gt>\&func> pairs relevant
to this element - see L<IUP::Manual::02_Elements|IUP::Manual::02_Elements/"new()">.

=head2 ATTRIBUTES

For more info about concept of attributes (setting/getting values etc.)
see L<IUP::Manual::03_Attributes|IUP::Manual::03_Attributes>. Attributes specific to this element:

=over

=item B<CALENDARWEEKNUMBERS>

Shows the number of the week along the year in the calendar. Default: NO.

=item B<FORMAT>

I<[Windows Only]>

Flexible format for the date in Windows. For more information see
L<"About Date and Time Picker Control"|https://msdn.microsoft.com/EN-US/library/windows/desktop/bb761726(v=vs.85).aspx>
in the Windows SDK. The Windows control was configured to display the
date only without any time options. Default: "d'/'M'/'yyyy". See the
notes below.

=item B<MONTHSHORTNAMES>

I<[Windows Only]>

Month display will use a short name instead of numbers. Must be set
before ORDER. Default: NO. Names will be in the language of the system.

=item B<ORDER>

Day, month and year order. Can be any combination of "D", "M" and "Y"
without repetition, and with all three letters. It will set the FORMAT
attribute in Windows. It will NOT affect the VALUE attribute order.
Default: "DMY".

=item B<SEPARATOR>

Separator between day, month and year. Must be set before ORDER in
Windows. Default: "/".

=item B<SHOWDROPDOWN>

I<(write-only)>

Opens or closes the dropdown calendar. Can be "YES" or "NO". Ignored if
set before map. In Windows, it works only for NO. (since iup-3.28)

=item B<TODAY>

I<(read-only)>

Returns the date corresponding to today in VALUE format.

=item B<VALUE>

The current date always in the format "year/month/day" ("%d/%d/%d" in
C). Can be set to "TODAY". Default value is the today date.

=item B<ZEROPRECED>

Day and month numbers will be preceded by a zero. Must be set before
ORDER in Windows. Default: NO.

=back

=head1 NOTES

In GTK it uses a custom control built with IUP elements, and in Windows
it uses DATETIMEPICK_CLASS.

In Windows, when the user navigates to other pages in the calendar the
date is not changed until the user actually selects a day.

In Windows, FORMAT can have the following values, but any other text in
the format string must be enclosed in single quotes:

=over

=item * B<"d"> - the one- or two-digit day. (B<default>)

=item * B<"dd"> - the two-digit day. Single-digit day values are preceded
by a zero. (Set when ZEROPRECED=Yes)

=item * B<"ddd"> - the three-character weekday abbreviation.

=item * B<"dddd"> - the full weekday name.

=item * B<"M"> - the one- or two-digit month number. (B<default>)

=item * B<"MM"> - the two-digit month number. Single-digit values are
preceded by a zero. (Set when ZEROPRECED=Yes)

=item * B<"MMM"> - the three-character month abbreviation. (Set when
MONTHSHORTNAMES=Yes)

=item * B<"MMMM"> - the full month name.

=item * B<"yy"> - the last two digits of the year (that is, 1996 would be
displayed as "96"). (Not recommended)

=item * B<"yyyy"> - the full year (that is, 1996 would be displayed as
"1996"). (B<default>)

=back
