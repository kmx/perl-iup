[% h.name %]

[% n.iupgllabel %]

[% h.desc %]

A label drawn by IUP on a GL canvas, which displays a text and/or an
image. It exists only inside an L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>.

[% h.usage %]

[% h.create %]

 my $lbl = IUP::GL::Label->new( TITLE=>'Label' );

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

[% h.at %]

[% txt.at_intro %]

=over

=item B<ALIGNMENT>

I<(non inheritable)>

Horizontal and vertical alignment.
Possible values: "ALEFT", "ACENTER" and "ARIGHT", combined to "ATOP",
"ACENTER" and "ABOTTOM". Default: "ALEFT:ACENTER". Partial values are
also accepted, like "ARIGHT" or ":ATOP", the other value will be
obtained from the default value.

=item L<FGCOLOR|[%m.at%]/FGCOLOR>

Text color. Can have an alpha component. Default: "0 0 0".

=item B<IMAGE>

I<(non inheritable)>

Image name. Use L<IUP::SetHandle|IUP::SetHandle> or
L<IUP::SetAttributeHandle|IUP::SetAttributeHandle> to associate an image
to a name. See also L<IUP::Image|IUP::Image>.

=item B<IMAGEHIGHLIGHT>

I<(non inheritable)>

Image name of the element in highlight state. If it is not defined then
the IMAGE is used.

=item B<IMAGEINACTIVE>

I<(non inheritable)>

Image name of the element when inactive. If it is not defined then the
IMAGE is used and its colors will be replaced by a modified version
creating the disabled effect.

=item B<IMAGEPRESS>

I<(non inheritable)>

Image name of the element in pressed state. If it is not defined then
the IMAGE is used.

=item B<IMAGEPOSITION>

I<(non inheritable)>

Position of the image relative to the text when both are defined. Can
be: LEFT, RIGHT, TOP, BOTTOM. Default: LEFT.

=item B<PADDING>

I<(non inheritable)>

Internal margin. Default value: "0x0".

=item B<CPADDING>

Same as PADDING but using the units of the B<SIZE> attribute. It will
actually set the PADDING attribute. (since iup-3.29)

=item B<SPACING>

I<(non inheritable)>

Defines the spacing between the image and the title. Default: "2".

=item B<CSPACING>

Same as SPACING but using the units of the vertical part of the B<SIZE>
attribute. It will actually set the SPACING attribute. (since iup-3.29)

=item L<TITLE|[%m.at%]/TITLE>

I<(non inheritable)>

Label's text. The '\n' character is accepted for line change.

=back

[% h.notes %]

The L<IUP::GL::Label|IUP::GL::Label> can contain text and image
simultaneously.

The natural size will be a combination of the size of the image and the
title, if any, plus PADDING and SPACING (if both image and title are
present).
