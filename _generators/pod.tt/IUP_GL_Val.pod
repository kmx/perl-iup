[% h.name %]

[% n.iupglval %]

[% h.desc %]

A slider/value selector drawn by IUP on a GL canvas, used to select a
value in a limited interval. It inherits from
L<IUP::GL::SubCanvas|IUP::GL::SubCanvas> and exists only inside an
L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>. (since iup-3.11)

[% h.usage %]

[% h.create %]

 my $v = IUP::GL::Val->new( VALUE=>0.3 );

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

[% h.at %]

[% txt.at_intro %]

The L<IUP::GL::Val|IUP::GL::Val> element handles all attributes defined
for the L<IUP::GL::SubCanvas|IUP::GL::SubCanvas> control.

=over

=item B<BACKIMAGE>

I<(non inheritable)>

Image name to be used as background. It will be zoomed to fill the
background (it does not include the border). Use
L<IUP::SetHandle|IUP::SetHandle> or
L<IUP::SetAttributeHandle|IUP::SetAttributeHandle> to associate an image
to a name. See also L<IUP::Image|IUP::Image>. IMPORTANT: for the slider
to match the handler movement area the BACKIMAGE must have a transparent
space that will leave room for the handler; at the extremes this space
should be at least half the handler size. (since iup-3.11.2)

=item B<BACKIMAGEHIGHLIGHT>

I<(non inheritable)>

Background image name of the element in highlight state. If it is not
defined then the BACKIMAGE is used. (since iup-3.11.2)

=item B<BACKIMAGEINACTIVE>

I<(non inheritable)>

Background image name of the element when inactive. If it is not defined
then the BACKIMAGE is used and its colors will be replaced by a modified
version creating the disabled effect. (since iup-3.11.2)

=item B<BACKIMAGEPRESS>

I<(non inheritable)>

Background image name of the element in pressed state. If it is not
defined then the BACKIMAGE is used. (since iup-3.11.2)

=item L<FGCOLOR|[%m.at%]/FGCOLOR>

Controls the bar color. Can have an alpha component. Default: "200 225 245".

=item B<FITTOBACKIMAGE>

I<(non inheritable)>

Enable the natural size to be computed from the BACKIMAGE. If BACKIMAGE
is not defined it will be ignored. When set to YES it will set
BORDERWIDTH to 0. Can be YES or NO. Default: NO. (since iup-3.11.2)

=item B<HANDLERSIZE>

I<(non inheritable)>

Handler size in the same direction as the ORIENTATION. Default: 0. If
set to 0 it will be calculated as half of the dimension opposite to the
ORIENTATION. If IMAGE is used it will be ignored (since iup-3.11.2). When
IMAGE is not used the handler size in the opposite direction is the size
of the element.

=item B<HLCOLOR>

Color used to indicate a highlight state. Can have an alpha component.
Default: "190 210 230".

=item B<IMAGE>

I<(non inheritable)>

Image name for the handler. Use L<IUP::SetHandle|IUP::SetHandle> or
L<IUP::SetAttributeHandle|IUP::SetAttributeHandle> to associate an image
to a name. See also L<IUP::Image|IUP::Image>. If defined the handler will
be replaced by the image.

=item B<IMAGEHIGHLIGHT>

I<(non inheritable)>

Image name of the element in highlight state. If it is not defined then
the IMAGE is used.

=item B<IMAGEINACTIVE>

I<(non inheritable)>

Image name of the element when inactive. If it is not defined then the
IMAGE is used and its colors will be replaced by a modified version
creating the disabled effect.

=item B<IMAGEPRESS>

I<(non inheritable)>

Image name of the element in pressed state. If it is not defined then the
IMAGE is used.

=item B<MAX>

Contains the maximum valuator value. Default: "1". When changed the
display will not be updated until VALUE is set.

=item B<MIN>

Contains the minimum valuator value. Default: "0". When changed the
display will not be updated until VALUE is set.

=item B<ORIENTATION>

I<(non inheritable)>

Informs whether the valuator is "VERTICAL" or "HORIZONTAL". Vertical
valuators go from bottom to top, and horizontal valuators go from left to
right, varying from MIN to MAX. Default: "HORIZONTAL".

=item B<SLIDERSIZE>

I<(non inheritable)>

Slider size in the same direction as the ORIENTATION. Default: 5. Ignored
when BACKIMAGE is used.

=item B<VALUE>

I<(non inheritable)>

Contains a number between MIN and MAX, indicating the valuator position.
Default: "0.0".

=back

[% h.cb %]

[% txt.cb_intro %]

=over

=item B<VALUECHANGED_CB>

Called after the value was interactively changed by the user.

[%h.at_handler%]

 sub valuechanged_cb_handler {
   my ($self) = @_;
   #...
 }

=over

B<$self:> reference to the element (IUP::GL::Val) that activated the event

=back

=item B<VALUECHANGING_CB>

Called when the value starts or ends being interactively changed by the user.

[%h.at_handler%]

 sub valuechanging_cb_handler {
   my ($self, $start) = @_;
   #...
 }

=over

B<$self:> reference to the element (IUP::GL::Val) that activated the event

B<$start:> flag that indicates if the value started to be changed (1) or
the change just ended (0).

=back
