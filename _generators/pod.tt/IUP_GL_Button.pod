[% h.name %]

[% n.iupglbutton %]

[% h.desc %]

A button drawn by IUP on a GL canvas, used inside an
L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>. When selected it activates a
function in the application. Its visual presentation can contain a text
and/or an image. It inherits from L<IUP::GL::Label|IUP::GL::Label>, and
exists only inside an L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>. (since iup-3.11)

[% h.usage %]

[% h.create %]

 my $b = IUP::GL::Button->new( TITLE=>'Button' );

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

[% h.at %]

[% txt.at_intro %]

The L<IUP::GL::Button|IUP::GL::Button> element handles all attributes
defined for the L<IUP::GL::Label|IUP::GL::Label> control, and consequently
for the L<IUP::GL::SubCanvas|IUP::GL::SubCanvas> control too.

=over

=item B<BACKIMAGE>

I<(non inheritable)>

Image name to be used as background. It will be zoomed to fill the
background (it does not include the border). Use
L<IUP::SetHandle|IUP::SetHandle> or
L<IUP::SetAttributeHandle|IUP::SetAttributeHandle> to associate an image
to a name. See also L<IUP::Image|IUP::Image>. (since iup-3.11.2)

=item B<BACKIMAGEHIGHLIGHT>

I<(non inheritable)>

Background image name of the element in highlight state. If it is not
defined then the BACKIMAGE is used. (since iup-3.11.2)

=item B<BACKIMAGEINACTIVE>

I<(non inheritable)>

Background image name of the element when inactive. If it is not defined
then the BACKIMAGE is used and its colors will be replaced by a modified
version creating the disabled effect. (since iup-3.11.2)

=item B<BACKIMAGEPRESS>

I<(non inheritable)>

Background image name of the element in pressed state. If it is not
defined then the BACKIMAGE is used. (since iup-3.11.2)

=item L<FGCOLOR|[%m.at%]/FGCOLOR>

Text color. Can have an alpha component. Default: "0 0 0". If TITLE and
IMAGE are both not defined then the button will show a color in a
rectangle using this attribute. (since iup-3.15)

=item B<FITTOBACKIMAGE>

I<(non inheritable)>

Enable the natural size to be computed from the BACKIMAGE. If BACKIMAGE
is not defined it will be ignored. When set to YES it will set
BORDERWIDTH to 0. Can be YES or NO. Default: NO. (since iup-3.11.2)

=item B<FRONTIMAGE>

I<(non inheritable)>

Image name to be used as foreground. It will be zoomed to fill the
foreground (it does not include the border). The foreground has the same
area as the background, but it is drawn last. Use
L<IUP::SetHandle|IUP::SetHandle> or
L<IUP::SetAttributeHandle|IUP::SetAttributeHandle> to associate an image
to a name. See also L<IUP::Image|IUP::Image>. (since iup-3.11.2)

=item B<FRONTIMAGEHIGHLIGHT>

I<(non inheritable)>

Foreground image name of the element in highlight state. If it is not
defined then the FRONTIMAGE is used. (since iup-3.11.2)

=item B<FRONTIMAGEINACTIVE>

I<(non inheritable)>

Foreground image name of the element when inactive. If it is not defined
then the FRONTIMAGE is used and its colors will be replaced by a modified
version creating the disabled effect. (since iup-3.11.2)

=item B<FRONTIMAGEPRESS>

I<(non inheritable)>

Foreground image name of the element in pressed state. If it is not
defined then the FRONTIMAGE is used. (since iup-3.11.2)

=back

=item L<ACTION|[%m.cb%]/ACTION>

Action generated when the button 1 (usually left) is selected. This
callback is called only after the mouse is released and when it is
released inside the button area.

 }

[% h.notes %]

The difference between an L<IUP::GL::Button|IUP::GL::Button> and an
L<IUP::GL::Label|IUP::GL::Label> is the border (controlled by
L<IUP::GL::SubCanvas|IUP::GL::SubCanvas> attributes BORDERWIDTH and
BORDERCOLOR), the change in background color for state feedback
(controlled by the PRESSCOLOR and HLCOLOR attributes), and the callback
to notify the application.

The natural size is the same as an L<IUP::GL::Label|IUP::GL::Label> plus
BORDERWIDTH.
