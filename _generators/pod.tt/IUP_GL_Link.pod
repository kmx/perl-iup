[% h.name %]

[% n.iupgllink %]

[% h.desc %]

A hyperlink label drawn by IUP on a GL canvas, which displays an
underlined clickable text. It is derived from
L<IUP::GL::Label|IUP::GL::Label> and exists only inside an
L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>.

[% h.usage %]

[% h.create %]

 my $link = IUP::GL::Link->new( URL=>'http://...', TITLE=>'IUP' );

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

[% h.at %]

[% txt.at_intro %]

=over

=item L<FGCOLOR|[%m.at%]/FGCOLOR>

Text color. Default: the global attribute LINKFGCOLOR.

=item B<URL>

The destination address of the link. Can be any text. If
L<IUP::Help|IUP::Help> is used it should be a valid URL. It can be
C<undef>. Default: "YES".

=back

[% h.notes %]

When the cursor is over the text, it is changed to the HAND cursor.

If the callback is not defined the L<IUP::Help|IUP::Help> function is
called with the given URL.
