[% h.name %]

[% n.iupflatbutton %]

[% h.desc %]

A button drawn by IUP itself with a flat appearance (it does not have
native decorations). When selected, this element activates a function in
the application. Its visual presentation can contain a text and/or an image.

It behaves just like an L<IUP::Button|IUP::Button>, but since it is not a
native control it has more flexibility for additional options and is fully
customizable. It can also behave like an L<IUP::Toggle|IUP::Toggle> (without
the checkmark). It inherits from L<IUP::Canvas|IUP::Canvas>.

[% h.usage %]

[% h.create %]

 my $b = IUP::FlatButton->new( TITLE=>'Click me' );

B<TITLE> is the text to be shown to the user. It can be C<undef>.

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

[% h.at %]

[% txt.at_intro %]

=over

=item B<ALIGNMENT>

I<(non inheritable)>

Horizontal and vertical alignment of the set image+text. Possible values:
"ALEFT", "ACENTER" and "ARIGHT", combined to "ATOP", "ACENTER" and
"ABOTTOM". Default: "ACENTER:ACENTER". Partial values are also accepted,
like "ARIGHT" or ":ATOP", the other value will be obtained from the default
value. Alignment does not include the padding area.

=item B<BACKIMAGE>

I<(non inheritable)>

Image name to be used as background. Use L<IUP::SetHandle|IUP::SetHandle> or
L<IUP::SetAttributeHandle|IUP::SetAttributeHandle> to associate an image to a
name. See also L<IUP::Image|IUP::Image>.

=item B<BACKIMAGEHIGHLIGHT>

I<(non inheritable)>

Background image name of the element in highlight state. If it is not defined
then the BACKIMAGE is used.

=item B<BACKIMAGEINACTIVE>

I<(non inheritable)>

Background image name of the element when inactive. If it is not defined then
the BACKIMAGE is used and its colors will be replaced by a modified version
creating the disabled effect.

=item B<BACKIMAGEPRESS>

I<(non inheritable)>

Background image name of the element in pressed state. If it is not defined
then the BACKIMAGE is used.

=item B<BACKIMAGEZOOM>

I<(non inheritable)>

If set the back image will be zoomed to occupy the full background. Aspect
ratio is NOT preserved. Can be Yes or No. Default: No. (since iup-3.25)

=item L<BGCOLOR|[%m.at%]/BGCOLOR>

Background color. If text and image are not defined, the button is configured
to simply show a color, in this case set the button size because the natural
size will be very small. If not defined it will use the background color of
the native parent.

=item B<HLCOLOR>

Background color used to indicate a highlight state. Pre-defined to
"200 225 245". Can be set to C<undef>. If C<undef> BGCOLOR will be used
instead.

=item B<PSCOLOR>

Background color used to indicate a press state. Pre-defined to "150 200 235".
Can be set to C<undef>. If C<undef> BGCOLOR will be used instead.

=item B<BORDER>

I<(creation only)>

The default value is "NO". This is the L<IUP::Canvas|IUP::Canvas> border.

=item B<BORDERCOLOR>

Color used for borders. Default: "50 150 255". This is for the
L<IUP::FlatButton|IUP::FlatButton> drawn border.

=item B<BORDERPSCOLOR>

Color used for borders when pressed or selected. Default use BORDERCOLOR.
(since iup-3.19)

=item B<BORDERHLCOLOR>

Color used for borders when highlighted. Default use BORDERCOLOR.
(since iup-3.19)

=item B<BORDERWIDTH>

Line width used for borders. Default: "1". Any borders can be hidden by
simply setting this value to 0. This is for the
L<IUP::FlatButton|IUP::FlatButton> drawn border.

=item B<SHOWBORDER>

By default borders are drawn only when the button is highlighted, if
SHOWBORDER=Yes borders are always shown. When SHOWBORDER=Yes and BGCOLOR is
not defined, the actual BGCOLOR will be a darker version of the background
color of the native parent. (since iup-3.25)

=item B<CANFOCUS>

I<(creation only, non inheritable)>

Enables the focus traversal of the control. Default: YES.

=item B<FOCUSFEEDBACK>

I<(non inheritable)>

Draw the focus feedback. Can be Yes or No. Default: Yes. (since iup-3.26)

=item B<PROPAGATEFOCUS>

I<(non inheritable)>

Enables the focus callback forwarding to the next native parent with FOCUS_CB
defined. Default: NO. (since iup-3.23)

=item L<EXPAND|[%m.at%]/EXPAND>

I<(non inheritable)>

The default value is "NO".

=item L<FGCOLOR|[%m.at%]/FGCOLOR>

Text color. Default: the global attribute DLGFGCOLOR.

=item B<TEXTHLCOLOR>

Text color used to indicate a highlight state. If not defined FGCOLOR will be
used instead. (since iup-3.26)

=item B<TEXTPSCOLOR>

Text color used to indicate a press state. If not defined FGCOLOR will be
used instead. (since iup-3.26)

=item B<FITTOBACKIMAGE>

I<(non inheritable)>

Enable the natural size to be computed from the BACKIMAGE. If BACKIMAGE is not
defined will be ignored. Can be Yes or No. Default: No.

=item B<FRONTIMAGE>

I<(non inheritable)>

Image name to be used as foreground. The foreground image is drawn in the same
position as the background, but it is drawn at last. Use
L<IUP::SetHandle|IUP::SetHandle> or
L<IUP::SetAttributeHandle|IUP::SetAttributeHandle> to associate an image to a
name. See also L<IUP::Image|IUP::Image>.

=item B<FRONTIMAGEHIGHLIGHT>

I<(non inheritable)>

Foreground image name of the element in highlight state. If it is not defined
then the FRONTIMAGE is used.

=item B<FRONTIMAGEINACTIVE>

I<(non inheritable)>

Foreground image name of the element when inactive. If it is not defined then
the FRONTIMAGE is used and its colors will be replaced by a modified version
creating the disabled effect.

=item B<FRONTIMAGEPRESS>

I<(non inheritable)>

Foreground image name of the element in pressed state. If it is not defined
then the FRONTIMAGE is used.

=item B<HASFOCUS>

I<(read-only)>

Returns the button state if it has focus. Can be Yes or No. (since iup-3.21)

=item B<HIGHLIGHTED>

I<(read-only)>

Returns the button state if highlighted. Can be Yes or No. (since iup-3.21)

=item B<IMAGE>

I<(non inheritable)>

Image name. Use L<IUP::SetHandle|IUP::SetHandle> or
L<IUP::SetAttributeHandle|IUP::SetAttributeHandle> to associate an image to a
name. See also L<IUP::Image|IUP::Image>.

=item B<IMAGEHIGHLIGHT>

I<(non inheritable)>

Image name of the element in highlight state. If it is not defined then the
IMAGE is used.

=item B<IMAGEINACTIVE>

I<(non inheritable)>

Image name of the element when inactive. If it is not defined then the IMAGE
is used and its colors will be replaced by a modified version creating the
disabled effect.

=item B<IMAGEPRESS>

I<(non inheritable)>

Image name of the element in pressed state. If it is not defined then the
IMAGE is used.

=item B<IMAGEPOSITION>

I<(non inheritable)>

Position of the image relative to the text when both are displayed. Can be:
LEFT, RIGHT, TOP, BOTTOM. Default: LEFT.

=item B<PADDING>

Internal margin. Works just like the MARGIN attribute of the
L<IUP::Hbox|IUP::Hbox> and L<IUP::Vbox|IUP::Vbox> containers, but uses a
different name to avoid inheritance problems. Alignment does not include the
padding area. Default value: "0x0". Value can be DEFAULTBUTTONPADDING, so the
global attribute of this name will be used instead. (since iup-3.29)

=item B<CPADDING>

Same as PADDING but using the units of the B<SIZE> attribute. It will actually
set the PADDING attribute. (since iup-3.29)

=item B<PRESSED>

I<(read-only)>

Returns the button state if pressed. Can be Yes or No. (since iup-3.21)

=item B<RADIO>

I<(read-only)>

Returns if the toggle is inside a radio. Can be "YES" or "NO". Valid only
after the element is mapped and TOGGLE=Yes, before returns C<undef>.

=item B<IGNORERADIO>

I<(non inheritable)>

When set the toggle will not behave as a radio when inside an
L<IUP::Radio|IUP::Radio> hierarchy. (since iup-3.21)

=item B<SPACING>

I<(non inheritable)>

Spacing between the image and the text. Default: "2".

=item B<CSPACING>

Same as SPACING but using the units of the vertical part of the B<SIZE>
attribute. It will actually set the SPACING attribute. (since iup-3.29)

=item L<TITLE|[%m.at%]/TITLE>

I<(non inheritable)>

Button's text. The '\n' character is accepted for line change.

=item B<TOGGLE>

Enables the toggle behavior. Default: NO.

=item B<TEXTALIGNMENT>

I<(non inheritable)>

Horizontal text alignment for multiple lines. Can be: ALEFT, ARIGHT or
ACENTER. Default: ALEFT. (since iup-3.22)

=item B<TEXTWRAP>

I<(non inheritable)>

For single line texts if the text is larger than its box the line will be
automatically broken in multiple lines. Notice that this is done internally by
the system, the element natural size will still use only a single line. For
the remaining lines to be visible the element should use EXPAND=VERTICAL or set
a SIZE/RASTERSIZE with enough height for the wrapped lines. (since iup-3.25)

=item B<TEXTELLIPSIS>

I<(non inheritable)>

If the text is larger than its box, an ellipsis ("...") will be placed near the
last visible part of the text and replace the invisible part. It will be
ignored when TEXTWRAP=Yes. (since iup-3.25)

=item B<TEXTORIENTATION>

I<(non inheritable)>

Text angle in degrees and counterclockwise. The text size will adapt to
include the rotated space. (since iup-3.25)

=item B<VALUE>

I<(non inheritable)>

Toggle's state. Values can be "ON", "OFF" or "TOGGLE". Default: "OFF". The
TOGGLE option will invert the current state. Valid only when TOGGLE=Yes. Can
only be set to ON for a toggle inside a radio, it will automatically set to OFF
the previous toggle that was ON.

=item B<SELECTED>

I<(non inheritable)>

Same as VALUE but ignores the TOGGLE attribute. Directly sets the selected
state but does not depend on a TOGGLE behavior. (since iup-3.31)

=back

[% h.cb %]

[% txt.cb_intro %]

=over

=item B<FLAT_ACTION>

Action generated when the button 1 (usually left) is selected. This callback
is called only after the mouse is released and when it is released inside the
button area. It mimics the L<IUP::Button|IUP::Button> ACTION callback.

[%h.at_handler%]

 sub flat_action_handler {
   my ($self) = @_;
   #...
 }

B<$self:> reference to the element (IUP::FlatButton) that activated the event

B<Returns:> IUP_CLOSE will be processed.

=item B<FLAT_BUTTON_CB>

Action generated when any mouse button is pressed or released. Same as the
L<IUP::Canvas|IUP::Canvas> BUTTON_CB callback.

[%h.at_handler%]

 sub flat_button_handler {
   my ($self, $button, $pressed, $x, $y, $status) = @_;
   #...
 }

B<$self:> reference to the element (IUP::FlatButton) that activated the event

B<$button:> identifies the activated mouse button

B<$pressed:> indicates the state of the button: 1 = pressed, 0 = released

B<$x>, B<$y>: position in the canvas where the event has occurred, in pixels

B<$status:> status of the mouse buttons and some keyboard keys at the moment
the event is generated (see L<IUP::Constants/"Keyboard and mouse status helpers">).

=item B<FLAT_ENTERWINDOW_CB>

Action generated when the mouse enters the button. Same parameters as the
L<IUP::Canvas|IUP::Canvas> ENTERWINDOW_CB callback.

[%h.at_handler%]

 sub flat_enterwindow_handler {
   my ($self) = @_;
   #...
 }

B<$self:> reference to the element (IUP::FlatButton) that activated the event

=item B<FLAT_FOCUS_CB>

Called when the button gets or loses the keyboard focus. Same as the
L<IUP::Canvas|IUP::Canvas> FOCUS_CB callback.

[%h.at_handler%]

 sub flat_focus_handler {
   my ($self, $focus) = @_;
   #...
 }

B<$self:> reference to the element (IUP::FlatButton) that activated the event

B<$focus:> non zero if the button is getting the focus, zero if it is losing
the focus.

=item B<FLAT_LEAVEWINDOW_CB>

Action generated when the mouse leaves the button. Same parameters as the
L<IUP::Canvas|IUP::Canvas> LEAVEWINDOW_CB callback.

[%h.at_handler%]

 sub flat_leavewindow_handler {
   my ($self) = @_;
   #...
 }

B<$self:> reference to the element (IUP::FlatButton) that activated the event

=item B<VALUECHANGED_CB>

Called after the value was interactively changed by the user. Called only when
TOGGLE=Yes. Called after the FLAT_ACTION callback, but under the same context.

[%h.at_handler%]

 sub valuechanged_handler {
   my ($self) = @_;
   #...
 }

B<$self:> reference to the element (IUP::FlatButton) that activated the event

=back

[% h.notes %]

The L<IUP::FlatButton|IUP::FlatButton> can contain text and image simultaneously.

The natural size will be a combination of the size of the image and the title,
if any, plus PADDING and SPACING (if both image and title are present).

Borders are drawn only when the button is highlighted reproducing the behavior
of the L<IUP::Button|IUP::Button> when FLAT=Yes.

Buttons are activated using Enter or Space keys.

When TOGGLE=Yes, to build a set of mutually exclusive toggles, insert them in a
L<IUP::Radio|IUP::Radio> container. Only the L<IUP::FlatButton|IUP::FlatButton>
controls inside the radio will be part of the exclusive group.

When TOGGLE=Yes, the button that is a child of an L<IUP::Radio|IUP::Radio>
automatically receives a name when it is mapped into the native system.
(since iup-3.16)

To replace a L<IUP::Button|IUP::Button> by a L<IUP::FlatButton|IUP::FlatButton>
you must change the function call (L<IUP::FlatButton|IUP::FlatButton> does not
include the action callback in the constructor) and change the ACTION callback
name to FLAT_ACTION.

To replace a L<IUP::Toggle|IUP::Toggle> by a L<IUP::FlatButton|IUP::FlatButton>
you must do the same, and set TOGGLE=Yes. But notice that there will be no
check box nor radio button.

Finally notice that the names of the secondary image attributes are different
(for instance IMINACTIVE is IMAGEINACTIVE, IMPRESS is IMAGEPRESS, and so on).
To define a button that only shows a color, do the same as in
L<IUP::Button|IUP::Button> and don't define TITLE nor IMAGE, but instead of
BGCOLOR use FGCOLOR to set the color of the button.

When the L<IUP::FlatButton|IUP::FlatButton> displays only a text it will look
like a label, use SHOWBORDER=Yes to force the display of the borders all the
time.
