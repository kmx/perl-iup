[% h.name %]

[% n.iupbackgroundbox %]

[% h.desc %]

A void container that simply draws a background. It can also be used as
a canvas, allowing the application to draw below the children. It
inherits from L<IUP::Canvas|IUP::Canvas>. (since iup-3.10)

[% h.usage %]

[% h.create %]

 my $box = IUP::BackgroundBox->new( child=>$something );

B<child>: An interface element which will receive the box. It can be
C<undef>.

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

[% h.at %]

[% txt.at_intro %]

=over

=item B<BACKIMAGE>

I<(non inheritable)>

Image name to be used as background. Use L<IUP::SetHandle|IUP::SetHandle>
or L<IUP::SetAttributeHandle|IUP::SetAttributeHandle> to associate an
image to a name. See also L<IUP::Image|IUP::Image>. When defined the
ACTION callback of the L<IUP::Canvas|IUP::Canvas> will be defined.
(since iup-3.26)

=item B<BACKIMAGEZOOM>

I<(non inheritable)>

If set the back image will be zoomed to occupy the full background.
Aspect ratio is NOT preserved. Can be "YES" or "NO". Default: "NO".
(since iup-3.26)

=item B<BACKCOLOR>

I<(non inheritable)>

If defined used to fill the background color when BACKIMAGE is defined.
If not defined BGCOLOR is used. (since iup-3.26)

=item L<BGCOLOR|[%m.at%]/BGCOLOR>

By default will use the background color of the native parent, but can
be set to a custom value. (since iup-3.11)

=item B<BORDER>

I<(creation only)>

The default value is "NO".

=item B<CANVASBOX>

I<(non inheritable)>

Enables the behavior of a canvas box instead of a regular container.
This will affect the EXPAND attribute, the Natural size computation, and
children layout distribution. Can be "YES" or "NO". Default: "NO".
(since iup-3.19)

=item B<CHILDOFFSET>

I<(non inheritable)>

Allows to specify a position offset for the child. Available for native
containers only. It will not affect the natural size, and allows to
position controls outside the client area. Format "I<dx>xI<dy>", where
I<dx> and I<dy> are integer values corresponding to the horizontal and
vertical offsets, respectively, in pixels. Default: "0x0".
(since iup-3.14)

=item L<CLIENTSIZE|[%m.at%]/CLIENTSIZE>

Returns the client size of the container, i.e. the size of the area
available for the child without the decorations (if any).

=item B<DECORATION>

I<(non inheritable)>

Enables a decoration area around the child. Can be "YES" or "NO".
Default: "NO". (since iup-3.20)

=item B<DECOROFFSET>

I<(non inheritable)>

Decoration offset from left border and top border in the format "XxY".
Used only when DECORATION=Yes. (since iup-3.20)

=item B<DECORSIZE>

I<(non inheritable)>

Total size of the decoration in the format "WidthxHeight". Used only
when DECORATION=Yes. (since iup-3.20)

=item L<EXPAND|[%m.at%]/EXPAND>

I<(non inheritable)>

Behaves as a container. See the CANVASBOX attribute.

=item B<CANFOCUS>

I<(non inheritable)>

The default is changed to "NO". But it can receive the focus.
(since iup-3.19)

=back

[% h.notes %]

The box can be created with no elements and be dynamically filled using
L<IUP::Append|IUP::Append> or L<IUP::Insert|IUP::Insert>.

The ACTION callback can be defined and the application can draw below
the other children inside the BackgroundBox, but only with the
L<IUP::Draw|IUP::Draw> API. To avoid overlapping the drawing areas it is
recommended that children must be inside native containers.
