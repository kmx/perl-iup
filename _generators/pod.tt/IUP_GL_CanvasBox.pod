[% h.name %]

[% n.iupglcanvasbox %]

[% h.desc %]

GUI element that is an OpenGL canvas which is also a container. It inherits
from L<IUP::CanvasGL|IUP::CanvasGL> and can host the OpenGL based controls of
the IUP GL library (such as L<IUP::GL::Button|IUP::GL::Button> and
L<IUP::GL::Label|IUP::GL::Label>), so it is the base element for building
OpenGL-drawn user interfaces. To use the GL controls inside your OpenGL canvas
you must replace the plain L<IUP::CanvasGL|IUP::CanvasGL> by an
L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>. (since iup-3.11)

It can have any number of children. Controls from the IUP GL library can be used
as children along with the void containers such as L<IUP::Hbox|IUP::Hbox>,
L<IUP::Vbox|IUP::Vbox>, and so on, including L<IUP::Fill|IUP::Fill>. Native
elements can also be placed on top although they will not be clipped by
L<IUP::GL::Frame|IUP::GL::Frame> and the other GL containers.

The elements that are a direct child of the box can be positioned using the
B<VERTICALALIGN> and/or B<HORIZONTALALIGN> attributes, or using a position in
pixels relative to the top-left corner of the box by setting the attribute
L<POSITION|[%m.at%]/POSITION>. Each direct child will be sized to its natural
size by default, except if B<EXPANDHORIZONTAL> or B<EXPANDVERTICAL> are set. The
box can be created with no elements and be dynamically filled using
L<IUP::Append|IUP::Append> or L<IUP::Insert|IUP::Insert>.

[% h.usage %]

[% h.create %]

 my $cnv = IUP::GL::CanvasBox->new( BUFFER=>'DOUBLE' );

B<Returns:> the identifier of the created element, or C<undef> if an error occurs.

[% h.at %]

[% txt.at_intro %]

=over

=item B<MARGIN>

I<(non inheritable)>

Defines a margin in pixels. Its value has the format "I<width>xI<height>",
where I<width> and I<height> are integer values corresponding to the horizontal
and vertical margins, respectively. Default: "0x0" (no margin).

=item B<REDRAW>

I<(non inheritable, write-only)>

Forces a full redraw of all elements and the main canvas.

=item B<HORIZONTALALIGN>

I<(non inheritable)> I<(at children only)>

Horizontally aligns the element inside the box. Possible values: "ALEFT",
"ACENTER", "ARIGHT" or "FLOAT". Default: "FLOAT". When FLOAT is used its
horizontal position is obtained from the L<POSITION|[%m.at%]/POSITION>
attribute.

=item B<VERTICALALIGN>

I<(non inheritable)> I<(at children only)>

Vertically aligns the element inside the box. Possible values: "ATOP",
"ACENTER", "ABOTTOM" or "FLOAT". Default: "FLOAT". When FLOAT is used its
vertical position is obtained from the L<POSITION|[%m.at%]/POSITION>
attribute.

=item B<EXPANDHORIZONTAL>

I<(non inheritable)> I<(at children only)>

Expands the horizontal size of the element to the box width. Works only if
EXPAND=Yes or HORIZONTAL. Can be Yes or No. Default: No. (since iup-3.13)

=item B<EXPANDVERTICAL>

I<(non inheritable)> I<(at children only)>

Expands the vertical size of the element to the box height. Works only if
EXPAND=Yes or VERTICAL. Can be Yes or No. Default: No. (since iup-3.13)

=item L<CLIENTSIZE|[%m.at%]/CLIENTSIZE>,
L<CLIENTOFFSET|[%m.at%]/CLIENTOFFSET>

Also accepted.

=item L<IUP::CanvasGL|IUP::CanvasGL> and L<IUP::Canvas|IUP::Canvas>

The L<IUP::GL::CanvasBox|IUP::GL::CanvasBox> element handles all attributes
defined for an OpenGL canvas and a conventional canvas.

=back

=item *

The L<IUP::GL::CanvasBox|IUP::GL::CanvasBox> element understands all callbacks
defined for the canvas (ACTION, BUTTON_CB, MOTION_CB, RESIZE_CB, WHEEL_CB,
etc.). These standard canvas callbacks are documented on
L<IUP::CanvasGL|IUP::CanvasGL> - refer to that page for their prototypes and
behavior.

[% h.notes %]

This control is itself an OpenGL canvas, so it supports the standard
L<IUP::CanvasGL|IUP::CanvasGL> callbacks and the C<GLMakeCurrent()> and
C<GLSwapBuffers()> methods inherited from it.

Because it has to forward the mouse and action callbacks to the IUP GL elements,
when it is mapped the callbacks ACTION, BUTTON_CB, MOTION_CB, WHEEL_CB and
LEAVEWINDOW_CB are replaced by internal callbacks. The application callbacks will
still be called and can be retrieved by using the prefix "APP_" on the callback
name. If for some reason the application sets one of these callbacks after being
mapped, the box internal callback can be retrieved by using the prefix "GLBOX_"
on the callback name.

Keyboard focus is NOT processed for L<IUP::GL::CanvasBox|IUP::GL::CanvasBox>
children.

The L<IUP::CanvasGL|IUP::CanvasGL> SWAPBUFFERS_CB callback is used internally to
enable a correct display for the box children. This means that when the
application calls C<GLSwapBuffers()>, the children will be drawn before actually
swapping the double buffer.
